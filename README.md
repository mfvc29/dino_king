# 🦖 Dino Rey · La leyenda de las siete piedras

Versión publicada del juego: portada, la Isla Pangea en 3D con el Dino Lector de mano y la página del Dino Lector.
Este repositorio se genera con `tools/publicar_juego.sh` desde el repositorio del editor; no se edita a mano.

- **Render** lo despliega con `render.yaml` (`python server.py`, modo público: sin editor y sin guardado en el servidor).
- **En local:** `python3 server.py` y abre http://localhost:8086
